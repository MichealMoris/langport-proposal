02 · Feature Scope

Five Core Modules

Every feature is engineered to handle learning, testing, sales, and administration — no third-party plugins, no compromise.

Module 01

🎓 LMS & User Dashboards

  • Student Dashboard: Course progress tracker, calendar view of booked sessions, and a secure resource library (PDFs, PPTs, course files).
  • Teacher Dashboard: Roster management, schedule overview, and a material upload tool to share files directly with enrolled students.
  • Private Accounts: Students and teachers interact through dedicated, role-based accounts — not static public pages.
Module 02

⚡ Interactive Placement Test Engine

  • Instant Online Testing: Interactive quiz format with multiple-choice or short-answer questions, inspired by systems like Wayground.
  • Real-Time Grading: The moment a student clicks "Submit," the website instantly calculates their score and level recommendation.
  • Automated Excel Pipeline: All test scores and answers are saved immediately and exported as a perfectly structured Excel/CSV file (Name, Phone, Test Date, Score, Level).
Module 03

💳 Course Booking & Online Payments

  • Course Catalog: Filter by language, level, teacher, or available times.
  • Method A — Automated Gateways: Paymob & Fawry. Credit/debit cards at 2.75% + 3 EGP; mobile wallets at 1.5%; Fawry kiosk at 2.75% + 3 EGP.
  • Method B — Direct Enrollment (0% Fees): Student fills a form → admin is alerted → payment via Vodafone Cash / InstaPay → admin activates the profile with one click.
Module 04

🔐 The Langport Store & Anti-Piracy Vault

  • Digital Storefront: A dedicated marketplace page where trainers, teachers, or parents browse educational resources.
  • Nothing Downloadable: Assets remain locked on the server. Users buy access to view — not to download.
  • PDFs & Worksheets: Custom web viewer disabling right-click, Print (Ctrl+P), and Download entirely.
  • PowerPoints (PPTs): Converted to interactive in-browser slide shows. Users click through slides but cannot save the file.
  • Payments Unlock Access: Automated (Paymob/Fawry) or manual (Vodafone Cash admin approval) — both unlock the viewer instantly.
Module 05

🖥️ Simplified Admin Control Panel

  • No coding required. An intuitive dashboard for the Langport team to manage the entire platform.
  • Course & Store Management: Add courses, upload assets — system auto-locks files in the secure viewer.
  • Manual Payment Activation: View "Request to Enroll" forms; activate with one click after payment confirmation.
  • Engagement Tracking: See which resources are viewed most, track total sales, and manage user access permissions.
  • Simple Blog System: Publish articles and updates to keep the website fresh and Google-friendly.

04 · Project Timeline

12-Week Delivery Roadmap

Divided by structural layers — database and backend logic first, interactive frontend interfaces second — ensuring a clean and stable build.

Weeks 1 – 2

Phase 1 · Architecture & Design Blueprints

  • MySQL database schema design: users, course schedules, enrollments, test questions, scores, and digital store assets.
  • Complete UI/UX wireframes for the home page, placement test wizard, store, and admin dashboards — fully optimized for mobile viewports.
Weeks 3 – 6

Phase 2 · Core Backend Engine & Data Pipelines

  • Authentication & Role Management: secure login pipelines with defined permission states (Students, Teachers, Admins).
  • Placement Test & Excel Logic: backend scoring engine calculating English levels; Excel/CSV pipeline generating perfectly structured downloads.
  • Transaction Engine: automated payment gateway responses (Paymob/Fawry) and manual approval states (Vodafone Cash / InstaPay admin toggles).
Weeks 7 – 10

Phase 3 · Frontend Interface & Livewire Interactions

  • Reactive Placement Test UI: multi-step, live-updating test wizard using Livewire — smooth on smartphones without heavy page reloads.
  • Course Catalog & Booking Menus: responsive course grids, schedule selectors, and checkout pages including custom manual booking request forms.
  • Secure Store & Anti-Piracy Viewer: marketplace frontend with custom scripts disabling right-click, Ctrl+P, Ctrl+S, and printing.
Weeks 11 – 12

Phase 4 · Integration, QA & Deployment

  • End-to-end system testing: full user path simulation (test → Excel export → purchase → locked asset viewing) on multiple iOS & Android screens.
  • SEO Setup: clean routing, fast loading times, meta tags, and launch of the Blog text editor.
  • Production Deployment: moving the full-stack Laravel application from staging to your live domain and cloud storage servers.
